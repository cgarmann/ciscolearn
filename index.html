Getting started

Never touched a Cisco device before? Start here.

What is Cisco IOS? IOS (Internetwork Operating System) is the software that runs on Cisco routers and switches. You interact with it through a command-line interface (CLI) — a text-based terminal where you type commands to configure the device.

What is Packet Tracer? Cisco Packet Tracer is a free network simulation tool. It lets you build virtual networks with routers, switches, and PCs — no physical hardware required. It's the standard tool for learning and practicing Cisco configurations.

Where do I start? Check out the PT Guides for step-by-step walkthroughs, or browse the Command Library to get familiar with the CLI.
