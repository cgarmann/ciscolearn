Subnetting Trainer

Practice calculating subnet values. You get a random IP and prefix — figure out the rest.

How subnetting works: An IP address has two parts — the network portion (determined by the prefix length) and the host portion. The network address has all host bits set to 0. The broadcast address has all host bits set to 1. Usable hosts = 2n − 2, where n is the number of host bits.
