Packet Tracer Guides

Step-by-step configuration walkthroughs for the most common Cisco Packet Tracer scenarios.

Configure a router from scratch — hostname, passwords, an interface with IP, and save.

01

Enter privileged EXEC mode

Click the router in Packet Tracer, go to the CLI tab, and press Enter if prompted.

Router> enable
Router#
02

Enter global configuration mode

Router# configure terminal
Router(config)#
03

Set hostname and disable DNS lookup

Router(config)# hostname Router-A
Router-A(config)# no ip domain-lookup
04

Set enable secret password

Router-A(config)# enable secret Cisco123
05

Configure a LAN interface

Replace GigabitEthernet0/0/0 with the correct interface for your model.

Router-A(config)# interface GigabitEthernet0/0/0
Router-A(config-if)# ip address 192.168.1.1 255.255.255.0
Router-A(config-if)# description LAN
Router-A(config-if)# no shutdown
Router-A(config-if)# exit
06

Save the configuration

Router-A(config)# end
Router-A# copy running-config startup-config
07

Verify

Router-A# show ip interface brief
Router-A# show running-config

Create VLANs, assign access ports, and configure a trunk link to a router.

01

Create VLANs

Switch(config)# vlan 10
Switch(config-vlan)# name Management
Switch(config-vlan)# exit
Switch(config)# vlan 20
Switch(config-vlan)# name Employees
Switch(config-vlan)# exit
02

Assign access ports to VLANs

Do this for each PC-facing port.

Switch(config)# interface FastEthernet0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

Switch(config)# interface FastEthernet0/2
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 20
Switch(config-if)# exit
03

Configure trunk port to router

The uplink to the router carries all VLANs.

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# exit
04

Verify

Switch# show vlan brief
Switch# show interfaces trunk

Route between VLANs using sub-interfaces on a single router port connected to a trunk.

01

On the switch — trunk the uplink

Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# switchport mode trunk
02

On the router — enable the physical interface

Router(config)# interface GigabitEthernet0/0/0
Router(config-if)# no shutdown
Router(config-if)# exit
03

Create sub-interfaces for each VLAN

Router(config)# interface GigabitEthernet0/0/0.10
Router(config-subif)# encapsulation dot1q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

Router(config)# interface GigabitEthernet0/0/0.20
Router(config-subif)# encapsulation dot1q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit
04

Set PC default gateways

VLAN 10 PCs → gateway 192.168.10.1
VLAN 20 PCs → gateway 192.168.20.1

05

Verify

Router# show ip route
Router# show ip interface brief

Configure the router to automatically assign IP addresses to clients on the LAN.

01

Exclude static addresses

Reserve the first 10 IPs for the router, switches, servers, and printers.

Router(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10
02

Create the DHCP pool

Router(config)# ip dhcp pool LAN
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8
Router(dhcp-config)# exit
03

Set PCs to use DHCP

In Packet Tracer: click PC → Desktop tab → IP Configuration → select DHCP.

04

Verify

Router# show ip dhcp binding
Router# show ip dhcp pool

Connect two routers via serial link and configure static routes so both sites can reach each other.

01

Configure serial interfaces on both routers

-- Router-A --
Router-A(config)# interface Serial0/1/0
Router-A(config-if)# ip address 10.0.0.1 255.255.255.252
Router-A(config-if)# no shutdown

-- Router-B --
Router-B(config)# interface Serial0/1/0
Router-B(config-if)# ip address 10.0.0.2 255.255.255.252
Router-B(config-if)# no shutdown
02

Add static routes

Each router needs a route to the other site's LAN, pointing to the neighbor's serial IP.

-- Router-A: route to Site-B LAN --
Router-A(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

-- Router-B: route to Site-A LAN --
Router-B(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1
03

Verify

Router-A# show ip route
Router-A# ping 192.168.2.1

Replace static routes with OSPF for automatic route discovery. All routers must be in the same area for a basic setup.

01

Configure OSPF on Router-A

Router-A(config)# router ospf 1
Router-A(config-router)# router-id 1.1.1.1
Router-A(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router-A(config-router)# network 10.0.0.0 0.0.0.3 area 0
Router-A(config-router)# passive-interface GigabitEthernet0/0/0
02

Configure OSPF on Router-B

Router-B(config)# router ospf 1
Router-B(config-router)# router-id 2.2.2.2
Router-B(config-router)# network 192.168.2.0 0.0.0.255 area 0
Router-B(config-router)# network 10.0.0.0 0.0.0.3 area 0
Router-B(config-router)# passive-interface GigabitEthernet0/0/0
03

Verify OSPF adjacency and routes

Router-A# show ip ospf neighbor
Router-A# show ip route ospf

You should see routes marked with O in the routing table.

Secure remote access to a Cisco device using SSHv2 and disable Telnet.

01

Set hostname and domain name

Router(config)# hostname Router-A
Router-A(config)# ip domain-name company.local
02

Generate RSA keys

Router-A(config)# crypto key generate rsa modulus 2048
03

Enable SSHv2 and create a local user

Router-A(config)# ip ssh version 2
Router-A(config)# username admin secret Str0ngP@ss
04

Restrict VTY lines to SSH only

Router-A(config)# line vty 0 15
Router-A(config-line)# transport input ssh
Router-A(config-line)# login local
Router-A(config-line)# exec-timeout 5 0
Router-A(config-line)# exit
05

Verify

Router-A# show ip ssh
Router-A# show users
